# SpeakBuddy

**开口说，才真的会。**（Speak up — that's when you really learn）一款浏览器版英语口语练习应用：兴趣定级、个性化学习路线、跟读逐词纠音，以及真实情景角色扮演对话。

## 简介

SpeakBuddy 是一个 100% 静态的单页 Web 应用，用来练习英语口语。**无需安装、无需注册、无需连接服务器**——用浏览器打开、允许麦克风，就能开口练。它完全基于浏览器内置能力（Web Speech 语音合成 / 语音识别、`getUserMedia` / `MediaRecorder`、Web Audio），只用原生 HTML、CSS 和 JavaScript：无依赖、无构建步骤、无后端。所有学习数据只保存在你自己的浏览器里（`localStorage`）；没有登录、没有数据上报、没有 AI / 大模型 API，也没有独立移动客户端。

## 功能特性

**定级测评与个性化路线**
- 引导流程：从 10 个内置兴趣话题中挑选，也可以添加自定义话题（自定义文本会映射到最接近的内置话题；匹配不到的话题会如实标注「课程规划中」）。
- 约 1 分钟的自适应入学测评：4 道跟读（口语）题，难度随得分升降；再加 2 道不需要麦克风的理解选择题。
- 结果给出 1 / 2 / 3 级（A2 初级 / B1 中级 / B2 高级）。兴趣决定「学什么」，水平决定「从哪开始」——起点之前的阶段全部开放为可选热身；重新测评只更新水平与路线，兴趣、星数与 XP 全部保留。
- 课程库：8 个主题单元 / 24 关 / 72 个跟读句子，含音标、音素重点与逐句提示。路线按兴趣相关度在三个难度阶段中挑选并排序部分关卡；关卡沿你自己的路线依次解锁，已通关的关卡随时可重练。

**跟读闯关**
- 先听标准发音（Web Speech TTS），再用麦克风录音（`getUserMedia` + `MediaRecorder`），同时由 Web Audio `AnalyserNode` 绘制实时音量波形。
- 浏览器 `SpeechRecognition` 给出识别文本；逐词对齐后与参考句比对，并为每个词着色（准确 / 接近 / 需纠正 / 漏读），附音素诊断建议。
- 三维评分：**准确度 / 流利度 / 完整度**，并给出星数、XP、等级、连击与成就。
- 自录音回放：每句结束后可回听自己的录音。

**情景对话**
- 12 个真实场景（机场、咖啡店、初次见面、问路、退换货、看诊、团队站会、小组作业、面试、委婉异议、远程协作、邀约婉拒），每个 4 轮。
- 对方先开口（TTS），你录下自己的回应。评分由**意图匹配**（同义关键词组 + 表达相似度，每轮有多种可接受说法）与**表达质量**（复用跟读评分）合成。
- 提供提示、每轮结束的 coach 点评，以及没有麦克风时用参考说法继续的「快速演示」。

**游戏化激励**
- XP 与等级（每 200 XP 升一级）、三星评价、连续高分连击（XP 加成最高 ×2）。
- 6 个成就徽章、7 天打卡连续天数、3 个每日任务与每日宝箱（25–55 XP 随机奖励），还有合成音效、彩带与全屏庆祝动画。
- **数据统计 / 进度页**（近 7 天活跃度、薄弱音素回顾）与**成就徽章页**。

**数据与隐私**
- 纯本地存储（`localStorage`），带冗余镜像用于自动恢复；不上传任何数据。
- JSON 备份导出 / 导入、用于跨设备迁移的精简**同步码**（`SB1:` 文本）、存储状态查看，以及完整的数据重置。

**发音**
- 基于 Web Speech API TTS：自动选择本地英语音色、在线 MP3 兜底，并提供音色、语速、诊断、设备测试音与引擎重置的设置弹窗。

## 快速开始

```bash
git clone <本仓库地址> speak-buddy
cd speak-buddy
python3 -m http.server 8000
# 或者：npx serve
```

用 Chrome 或 Edge 打开 **http://localhost:8000**。

- 建议用本地 Web 服务器（或任意 HTTPS 站点），而不是直接双击 `index.html`：麦克风与语音识别需要**安全上下文**（`localhost` 或 HTTPS）并授予麦克风权限。
- **GitHub Pages 部署**：没有构建步骤，直接推送静态文件即可。自定义域名由 [CNAME](CNAME) 配置：`speak-buddy.riemann-chow.cn`。

## 浏览器支持

| 浏览器 | 语音识别 | 发音 | 体验 |
| --- | --- | --- | --- |
| Chrome / Edge | 完整（`webkitSpeechRecognition`） | 本地内置音色，在线 MP3 兜底 | **推荐**，可获得真实逐词评分 |
| Safari | 部分 / 不可用 | 可用时用内置 TTS，否则在线 MP3 | 真实评分依赖识别结果；否则可开启体验模式 |
| Firefox | 部分 / 不可用 | 在线 MP3 兜底 | 真实评分依赖识别结果；否则可开启体验模式 |

- **麦克风与安全上下文**：`getUserMedia` 和语音识别仅在 `localhost` 或 HTTPS 下可用，并需在弹窗中允许麦克风。
- **自动播放策略**：浏览器要求页面先有一次用户手势才能朗读。首次播放在点击内同步触发，因此点一下播放就一定有声音。
- 缺少内置语音引擎的浏览器会自动回退到在线音频发音。缺少语音识别的浏览器无法给出真实评分：静音 / 未识别的录音会显示 0 分结果，并提供一键开启**体验模式**的入口，开启后才是明确标注的模拟评分。

## 评分机制

1. **识别文本与逐词对齐。** 识别结果先做归一化（缩略形式、标点）并分词，再用 Needleman–Wunsch 风格动态规划 + 编辑距离词相似度与参考句对齐。每个参考词被标为 `准确 / 接近 / 需纠正 / 漏读`，多读的词也会被检出。
2. **三个维度。**
   - *准确度*（52%）：词与词的匹配程度。
   - *流利度*（24%）：实际时长与理想节奏的偏差、停顿次数、音量。
   - *完整度*（24%）：句子覆盖程度（漏读 / 多读）。
   - 加权得到 0–100 总分 → 星数（≥88 三星，≥72 二星，≥55 一星）→ XP 与连击。
3. **诚实处理无声 / 未识别。** 静音或无法识别的录音**不会**得到及格分。若没有识别到语音，结果显示 **「no speech detected / 未检测到声音」**，**0 分**，不发放 XP / 星数 / 连击，并提供**重试**按钮。
4. **体验模式（Experience mode，又称 demo 模式）。** 由你手动开启（也可在「未检测到声音」结果页一键开启），分数才是明确标注的**模拟值**（XP 减半），用于完整演示流程；系统不会自动开启它，因此没说话绝不会悄悄拿到及格分。真实分数与模拟分数绝不混在一起。
5. **对话评分。** 意图匹配（62%）+ 表达质量（38%，复用跟读评分）→ 总分、星数与 coach 点评。

## 发音与 TTS

- 发音使用浏览器的 Web Speech `speechSynthesis`。加载时会**自动选择并保存一个本地英语音色**；若朗读卡住，会自动改用浏览器默认音色、恢复常速重试一次。
- **首次播放在点击内同步触发**，符合自动播放策略；点一下播放就一定有声音。
- 若内置引擎**启动失败（或浏览器根本不提供）**，应用会自动回退到**在线 MP3 发音**。长句会按词切成短块（部分词典发音接口有词数上限），每块依次尝试三个来源：有道 `dictvoice`、百度翻译 TTS、Google 翻译 TTS。这些是**第三方公开接口，不属于本项目、也不由本项目运营**，需要联网；应用本身不附带任何音频文件。仅发送内置句子文本，绝不上传你的录音。
- **设置弹窗**（顶栏耳机图标，发音设置）仍可手动选择英语音色与语速、查看**诊断信息**（引擎支持情况、音色数量、引擎状态、上次朗读）、播放**设备测试音**（Web Audio，绕开语音引擎）、**重置语音引擎**、试听例句、恢复默认。点击逐词卡片也能单独朗读该词。

## 数据与隐私

所有数据**只保存在浏览器的 `localStorage`** 中——无后端、无账号、无服务端副本：

| 键 | 内容 |
| --- | --- |
| `speakbuddy.v1` | 进度：兴趣、定级、路线、关卡、对话、XP、等级、连击、打卡、每日任务、成就、设置 |
| `speakbuddy.v1.mirror` | 冗余镜像，用于主存档损坏 / 被删时自动恢复 |
| `speakbuddy.tts.v1` | TTS 音色与语速偏好 |

数据按**来源**（协议 + 域名 + 端口）隔离。清除浏览器数据、无痕窗口、换浏览器 / 换设备，或在 `file://`、`http://localhost:8000` 与不同端口 / 域名之间切换，都会得到互不相通的空存档。通过**「我的学习记录」**弹窗可以：

- 查看存储状态与记录数量；
- **导出 JSON 备份文件**并**导入**（包含完整每日明细）；
- **复制 / 粘贴同步码**（`SB1:` + 精简存档的 base64），无需文件即可跨地址、跨设备迁移进度；
- **重置全部学习数据**（清空一切并回到首次引导）。

恢复会覆盖当前记录；换地址或清除数据前，请先保存备份或同步码。

## 开发说明

- **无构建步骤。** 改完任意文件刷新即可；用任意静态服务器托管该目录。
- **缓存戳**：修改 JS / CSS 后，请同步递增 [index.html](index.html) 中 `<link>` 与 `<script>` 上的 `?v=N` 查询串（目前为 `?v=11`），让浏览器加载到新文件。
- **代码风格**：ES5 风格 JavaScript；每个模块都是一个 IIFE，挂到统一的全局命名空间，例如 `window.SB.data`、`window.SB.store`、`window.SB.speech`、`window.SB.scoring`、`window.SB.app`。`index.html` 中的脚本加载顺序有依赖关系（data → speech → recorder → scoring → assessment → dialogue → store → route → fx → app）。
- **路由**：哈希路由（`#/home`、`#/practice/<关卡 id>`、`#/dialogue[/<场景 id>]`、`#/stats`、`#/achievements`、`#/finish/<关卡 id>`）。
- **部署**：纯静态站点，推送到 GitHub Pages（保留 `CNAME` 文件）即可。

## 常见问题

- **点了播放没声音？** 再点一次（用户手势会解锁自动播放），然后打开 发音设置 →「测设备音量」和「重置语音引擎」。若本地引擎启动失败，系统会自动切换到在线 MP3 兜底，该兜底需要联网。
- **没有分数 / 显示「未检测到声音」？** 请确认已授予麦克风权限、运行在 `localhost` / HTTPS 上，并使用 Chrome 或 Edge；清晰地朗读后点**重试**。这个 0 分结果是刻意设计的——静音绝不会拿到及格分。
- **麦克风被拒或没有麦克风？** 发音仍可用（本地引擎或在线 MP3），**体验模式（Experience mode）**提供明确标注的模拟分数，你依然可以浏览所有页面。

---

SpeakBuddy 是一个静态、零依赖的学习小应用：识别、评分、存储全部在浏览器本地完成。仅当内置语音引擎启动失败时，才会把句子文本发给第三方 TTS 接口播放在线 MP3；你的录音和学习数据绝不会离开设备。
